# Portfolio

Web personal de Cristian Ramón Noguera. HTML, CSS y JavaScript sin dependencias, servida con GitHub Pages.

- `index.html`: contenido de la página.
- `styles.css`: estilos.
- `main.js`: menú móvil, animaciones y formulario de contacto (abre el cliente de correo).
- `assets/`: foto y CV en PDF.
